# IG 分類器（instagram-gist）

Chrome 擴充功能：把你的 IG 追蹤名單和收藏自動分類，再為每個收藏分類產生重點摘要。

## 背景

IG 收藏一多就找不到，追蹤名單也混在一起。IG 自己的收藏分類要一則一則手動放。

這個擴充功能做三件事：

1. 用 Gemini 把追蹤和收藏分成主題（美髮、行銷、滑雪…）。
2. 用規則把個人好友從追蹤名單拆出來，放進「好友」分類。
3. 為每個收藏分類寫重點摘要，每一點都連回原始貼文，不用再一則一則打開。

所有資料只存在你這台電腦。現階段只給自己用，沒有上架 Chrome 線上應用程式商店。

## 安裝

需要：

| 項目 | 版本 / 說明 |
|---|---|
| Chrome（或其他 Chromium 瀏覽器） | 116 以上 |
| Instagram 帳號 | 在同一個瀏覽器登入 instagram.com |
| Gemini API key | 免費申請：<https://aistudio.google.com/apikey> |
| Node.js | 只有跑測試才需要，已在 22 測過 |

步驟（約 3 分鐘）：

1. 下載這個專案：
   ```bash
   git clone https://github.com/wade790720/instagram-gist.git
   ```
2. Chrome 網址列輸入 `chrome://extensions`。
3. 打開右上角「開發人員模式」。
4. 按「載入未封裝項目」，選這個資料夾。
5. 按工具列的擴充功能圖示。第一次打開會進「設定」頁，貼上 Gemini API key，按「儲存」。

## 使用方式

### 同步與分類

1. 按右上角「同步」。擴充功能會抓收藏、追蹤名單和粉絲名單，再自動分類。
2. 用上方的分類標籤篩選，或用搜尋框找帳號、文字。
3. 分錯了：用每一列右邊的下拉選單改分類，或選「＋ 新分類…」。手動改過的分類，之後重新分類也不會被蓋掉。
4. 編輯分類：按選取中分類旁的「⋯」，或在任何分類上按右鍵，選「編輯」或「刪除」。
   - 編輯：分類標籤直接變成輸入框。按 Enter 儲存，按 Esc 或點別處取消。打已有的分類名稱，上方會先提示，按 Enter 後兩個分類合併，摘要也合併。
   - 刪除：裡面的項目變成未分類，下次分類時由 AI 重新分。
5. 分類中途額度用完：之後按「還有 N 筆未分類 · 開始分類」接著分，不會重抓 IG。

### 摘要

1. 在「收藏」分頁點一個分類，按「產生摘要」。
2. 摘要每一點後面的 `[2][5]` 可以點，會打開那則原始貼文。
3. 想換寫法：在摘要下方輸入指示，例如「收斂成公式：銷售 = 痛點情境 + 解決方案」。
   - 按「改寫這份」：改寫目前這份。指示會保留，之後更新也會套用。
   - 按「另存成新摘要」：目前這份不動，另外產生一份新的。一個分類可以有多份摘要。
4. 有新收藏時會出現「有 N 則新收藏 · 更新摘要」。舊的 `[n]` 編號不變，新貼文排在後面。
5. 改壞了按「復原上一版」（只保留一版）。
6. 「摘要」分頁會列出所有分類的所有摘要。

### 設定

| 欄位 | 預設值 | 說明 |
|---|---|---|
| 分類用的模型 | `gemini-3.5-flash-lite` | 呼叫次數多，選免費額度高的 |
| 摘要用的模型 | `gemini-3.8-flash` | 選寫作品質好的。忙碌（503）時自動改用分類用的模型 |
| 分類與摘要的語言 | 跟瀏覽器語言 | 繁體中文或英文 |

「全部重新分類」會清掉所有自動分類和摘要，手動改過的分類會保留。

## 運作方式

```
擴充功能頁面 ──注入程式──▶ instagram.com 分頁（用你自己的登入狀態抓清單）
      │
      ├──▶ Gemini：分類（追蹤每批 400 個、收藏每批 150 則）、按需寫摘要
      └──▶ chrome.storage.local：清單、分類、摘要都只存在這台電腦
```

- **只有按「同步」才會抓 IG。** 打開頁面不會自動抓，降低帳號被鎖的風險。
- **收藏**：每次同步只抓新的，遇到已抓過的就停。
- **追蹤**：整份重抓，但不管按幾次，每天最多一次。
- 每頁之間隨機停 2–5 秒，不要調快。
- **好友**用規則判斷，不用 AI：沒有藍勾，而且有回追你或是私人帳號。互追的小店家也會被放進來，手動改一次就好。

## 已知限制

| 限制 | 何時處理 |
|---|---|
| 摘要只讀文字說明和 IG 自動圖片描述，不讀 Reels 語音 | 接上 Brand Digest 的轉錄 |
| 第一次匯入收藏最多約 1000 則，更舊的抓不到 | 有需要再存下次的分頁位置 |
| 取消收藏不會被偵測 | 有需要再加「整份重抓」 |
| 列表最多顯示 500 筆 | 清單變更大再加分頁 |
| 只能在電腦用 | 加 Cloudflare 同步後做手機網頁版 |
| IG 改內部 API 就會壞 | 壞了再修 `app.js` 的 `igFetch` |

## 開發

```bash
node test.js
```

沒有輸出就是通過。

| 檔案 | 用途 |
|---|---|
| `core.js` | 純邏輯，不用 Chrome API，`test.js` 測的就是它 |
| `app.js` | 介面、抓 IG、呼叫 Gemini |
| `app.html` | 頁面與樣式 |
| `background.js` | 點工具列圖示時，打開或切到唯一的 app 分頁 |
| `_locales/` | 介面文字（英文、繁體中文） |

改完程式後，在 `chrome://extensions` 按擴充功能的重新整理鈕，再重新打開頁面。
