# IG 分類器（IG Sorter）

Chrome 擴充功能：把你的 IG 追蹤名單和收藏自動分類，再為每個收藏分類產生重點摘要。
現階段只給自己用。

## 安裝（約 3 分鐘）

1. Chrome 網址列輸入 `chrome://extensions`
2. 打開右上角「開發人員模式」
3. 按「載入未封裝項目」，選這個資料夾
4. 在同一個瀏覽器登入 instagram.com
5. 按工具列的擴充功能圖示 → 「設定」填 Gemini API key（免費：https://aistudio.google.com/apikey）

## 運作方式

```
擴充功能頁面 ──注入程式──▶ instagram.com 分頁（用你自己的登入狀態抓清單）
      │
      ├──▶ Gemini：每批 80 則分類、按需寫摘要
      └──▶ chrome.storage.local：清單、分類、摘要都只存在這台電腦
```

- **只有按「同步」才會抓 IG**，打開頁面不會自動抓，降低帳號被鎖的風險。
- **收藏**：每次同步只抓新的，遇到已抓過的就停。
- **追蹤**：整份重抓，但不管按幾次，每天最多一次。
- 每頁之間隨機停 2–5 秒，不要調快。

## 已知限制

| 限制 | 何時處理 |
|---|---|
| 摘要只讀文字說明和 IG 自動圖片描述，不讀 Reels 語音 | 接上 Brand Digest 的轉錄 |
| 只能在電腦用 | 加 Cloudflare 同步後做手機網頁版 |
| 取消收藏不會被偵測 | 有需要再加「整份重抓」 |
| 不能手動改分類 | 有需要再加 |
| IG 改內部 API 就會壞 | 壞了再修 `app.js` 的 `igFetch` |

## 開發

```bash
node test.js
```

沒有輸出就是通過。`core.js` 是純邏輯，`app.js` 是介面與 Chrome API。
